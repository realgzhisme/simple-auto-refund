# simple-auto-refund

项目初始化仓库，功能代码与技术栈待补充。

## 本地开发

```bash
git clone https://github.com/realgzhisme/simple-auto-refund.git
cd simple-auto-refund
```

## 配置与提交约定

- 本地环境变量使用 `.env` 或 `.env.local`，不要提交真实凭据。
- 需要共享配置模板时，使用 `.env.example`，仅填写占位值。
- `.gitignore` 已排除常见依赖目录、构建产物、日志、IDE 本地配置及密钥文件。
- 依赖锁文件应提交到版本库，保证依赖版本可复现。
- 新增技术栈后，补充安装、启动和测试说明。
